Leak-CURBER NeurIPS 2026

Leak-CURBER is a benchmark for enzymatic reaction tasks with leakage-aware data splits. It covers kinetic parameter prediction, binding affinity, enzyme classification, enzyme retrieval, and reaction outcome. Project page · Code

SPECTRA bioRxiv 2026

SPECTRA reconstructs metabolic models from multi-omics data at many scales. These range from minimal reactomes and context-specific models to microbial community and multi-tissue models. MATLAB code · Python code · Docs

ThermOptCOBRA iScience 2025

ThermOptCOBRA finds and removes thermodynamically infeasible cycles in genome-scale metabolic models. This gives more reliable phenotype predictions and context-specific models. Paper · MATLAB code · Python code

NovoMolGen arXiv 2025

NovoMolGen is a family of transformer foundation models pretrained on 1.5 billion molecules for de novo molecule generation. It outperforms prior molecular language models in unconstrained and goal-directed generation. The paper is on arXiv under the title “A Large Scale Investigation of Scaling Limits in Chemical Language Models”. Paper · Code

BiCA AAAI 2026

BiCA trains biomedical dense retrieval models with hard negatives taken from the PubMed citation graph. The repository holds the pipeline to build the corpus, train the model, and evaluate it. Paper · Code

Functional groups for molecular property prediction JCIM 2026

FGMolProp predicts molecular properties from the functional groups in a molecule. This gives representations that chemists can interpret, and it works on more than 35 datasets. Paper · Code
